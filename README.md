# ProxyChecker

**ProxyChecker** is a tool designed to check the validity and speed of proxy servers. It allows users to input a list of proxies and tests their responsiveness, connection speed, and overall reliability.

## Features
- Check the validity of multiple proxy servers.
- Measure and display the connection speed for each proxy.
- Provide detailed results on the responsiveness and reliability of proxies.
- Support for different proxy types (HTTP, HTTPS, SOCKS).

## Technologies Used
- **C#** for backend logic.
- **.NET Core** for application structure.
- **Multi-threading** to speed up proxy checking for large lists.

## How to Use

### 1. Clone the Repository:
```bash
git clone https://github.com/dursunkatar/ProxyChecker.git
```
### 2. Open and Run:
- Open the project in Visual Studio and build the solution.
- Run the application and input your list of proxy servers.
- Start the check, and the tool will display the results including validity and speed.

### 3. Proxy Checking Results:
-  The results will show if the proxy is valid, its connection speed, and whether it is suitable for further use.
